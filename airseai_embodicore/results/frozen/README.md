# Frozen Part-III records

Files in this directory are **frozen claim/audit records**.

`PART3_FROZEN_SUMMARY.json` consolidates values from the previously frozen
Part-III.5 result write-up. `PAPER_CLAIM_INDEX.csv` maps headline manuscript
claims to their shipped evidence layer.

These files are intentionally not labeled raw data and do not independently
reproduce the historical 4,096-candidate DSE or action replay.
